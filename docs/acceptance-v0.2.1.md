# v0.2.1 验收记录

验收日期：2026-09-30 至 2026-10-01。对象：本机研序，http://127.0.0.1:8920/。

## 原问题与原因

读取了用户原有紫金矿业对话 `761759870c414bb4`：该对话未调用资料工具，模型声称没有上传入口。v0.2 的资料库已有基础上传，但未提供聊天上传、将新文件接入已有对话或自动查找公开年报的完整流程；历史也没有删除入口。原因是功能缺失和模型能力说明过时，不是 Tushare Token。

## 本次实现

- 公司研究、关联对话可移入回收站并恢复。删除正在运行的任务会被拒绝；删除研究时关联对话一并移入，原始 PDF 保留在资料库。
- 聊天输入区新增“上传 PDF”“接入资料”“查找年报”。文件接入已有研究，无需重建底稿。
- 巨潮公开披露自动查找年度报告全文：校验公司、年度、公告日、来源域名；排除摘要和半年报。查询下载不读取 Tushare Token。
- PDF 上限扩展到 100 MB / 800 页，全文索引、关键词检索、按物理页码阅读、原文链接、扫描页按需 Windows OCR。
- 新材料随研究保存、可进入导出证据包，但不会自动改写已核验事实。
- 限制重复检索；修复“不修改报告”被误判为必须修改的问题。用户指定读页时增加实际调用检查，并保留查阅链接。
- 针对股本余额的已知单位混淆增加原文检查；同额股本金额不得无依据改写成股份数量。该检查不是完整财务核验器。

## 实际浏览器与联网验收

使用单独验收对话 `5c184f3a24944052`，绑定原研究 `229034c9b0bc4b57`。原用户对话内容保留。

1. 删除验收对话、在回收站恢复成功，恢复后可以继续使用。见 `history-trash-v0.2.1.png`。
2. 从巨潮发现并下载紫金矿业 2025 年年报全文，352 页、79,925,886 字节。文件 ID `ea24fb272e2e4a0e`；[公开来源](https://static.cninfo.com.cn/finalpage/2026-03-21/1225550242.PDF)。随后浏览器“查找年报”成功完成查询、复用已下载文件并接入，未重复创建副本。
3. 从浏览器文件选择框实际上传 `zijin-2025-annual-summary.pdf`，315,157 字节、7 页，文件 ID `971df700c09049f8`；[公开来源](https://static.cninfo.com.cn/finalpage/2026-03-21/1225023677.PDF)。界面材料数从 1 增至 2，原研究数保持 9。
4. 真实模型限定使用上传摘要，检索并回答第 4 页的营业收入 349,079,082,852 元、经营现金流净额 75,429,516,296 元；与实际提取的第 4 页表头和数值一致。页面显示可点击来源链接。
5. 后续明确要求按页读取，真实工具成功读取摘要第 4 页、全文第 244 页与全文第 120 页；其中第 120 页保留 `windows_ocr` 标记，回复说明未核验原图。OCR 先由后端实际识别验收并缓存，模型本轮复用缓存；并非声称该轮重新运行 OCR。
6. 原研究仍为 6 项结构化事实、报告第 1 版、0 份估值情景；这些查阅没有把新材料金额直接写入底稿。
7. 最终真实模型重新读第 244 页，检索“股份总数”，再读取第 83 页；成功更正股本余额 2,658,973,314 元与股份总数 26,589,733,140 股的区别。第 83 页实际文字表头为“单位：股”，期末行与答复一致。

## 验收中发现并修复的问题

- 首次年报查询后模型重复关键词检索至预算耗尽。发现全文的财务主表第 113–128 页为扫描图像（另有第 108 页扫描审计页），随后接入本机 OCR、返回无文本页定位并限制重复检索。
- 否定句“不修改报告”被执行后置校验误判，导致模型已生成的答复不能结束；已修正并加入回归测试。
- 严格读页反馈仅给出内部字段名时，模型未理解；改为明确的工具调用说明，只对用户指定页码或逐页阅读要求检查实际读页。
- 模型曾传入一次读 7 页，工具明确拒绝；随后检索找到了所需片段。每次 1–3 页的边界保留，工具失败在界面可见；后续按页读取验收成功。
- 真实模型把“人民币元”表头下的股本余额误写为股数，单纯提示词仍未纠正。新增确定性单位冲突检查，最多要求纠正一次，仍冲突则给出安全的待核实说明和原文链接。旧错误答复留作测试记录，不作为有效财务结论。

最终 `python -m pytest -q`：**70 passed**（16.90 秒），仅有 Starlette TestClient 的既有弃用提示。前端 TypeScript / Vite 构建通过。浏览器验收结束未记录到前端 console error。服务健康检查返回 0.2.1；PDF 文件接口的字节区间请求返回 `206 application/pdf` 和 `%PDF-` 文件头。内嵌浏览器的 PDF 页码定位未单独确认，不将点击链接等同于验证其 PDF 查看器跳页行为。

公开站点可能限流、调整接口或替换附件；披露日过滤不等于保证严格的历史附件版本。OCR 可能误读金额和列关系，现阶段仍需核对原图。模型也可能误解上下文或口径；已增加的股本校验只能覆盖特定已知错误。新增 PDF 阅读能力不代表完整三表建模、自动财务事实合并或通用网页搜索已经完成。
