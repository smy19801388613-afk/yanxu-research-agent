## 已落实的结果

- 最新消息中的明确只读、离线、禁止写报告和禁止估值约束在执行层检查，修复“保存的材料……不改报告”的跨分句误判。
- 资料覆盖按实际工具日志呈现；摘要不计正文，读取失败保留缺口。侧栏合并来源、优先展示已读正文，显示总数并可展开全部。
- 报告关联具体估值引用或生成时冻结的输入快照；新情景与旧稿不一致时提示对照，历史内容不自动覆盖。
- 负基期显示金额变化：本例归母亏损收窄 3.20 亿元、经营现金流改善 0.86 亿元，用中性色表示，未强算增长率。
- 报告目录前置，章节及核实问题可预填到聊天；PDF 类型使用“PDF 原文”，不再一律称为年报。
- 当前报告与完整审计导出分开，已有 PDF 在 ZIP 内使用相对路径并保留页码。全部旧稿与原始 JSON 仍可取得。

## 下一轮优先级

1. **让研究问题决定完成状态**：现在能判断有没有读到正文，仍不能判断“具体竞争者、收费证据、分项现金流归因”是否逐项回答。成长重放仍有通用竞品判断和超出证据的措辞，应做问题级证据清单及反例测试。
2. **改善被拒绝后的执行**：搜索次数达到上限后应及时改读已有线索或收束，不能重复消耗模型决策。实际四次被拒绝没有额外联网，但产品效率仍不理想。
3. **约束金融语义与来源等级**：接口单源事实仍可能被模型称为“已核验”，部分答案用不可点击的来源 ID；需要逐项来源绑定和状态校验。正文阅读数不等于研究可信度。
4. **提高搜索相关性并深入官网链接**：本轮免费检索仍返回无关公司公告，读官网首页不足以回答产品收费或具体竞争格局；有价值的下一步是受问题驱动的二级原文阅读。
5. **章节差异比较与建模深度**：保留旧稿和修订说明已经实现，章节前后对照暂缓；完整三表、经营驱动预测与情景概率仍不是本轮完成范围。

这些是本次真实试用保留下来的研发问题，不以增加装饰、来源数量或一段更强的提示词替代验证。
