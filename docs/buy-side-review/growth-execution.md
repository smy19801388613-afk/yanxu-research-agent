## 变更与行为

### 1. 最新用户约束同时控制意图与实际分派

新增 turn_constraints，将中文标点与否定边界归一解析。禁止联网、只用已保存材料、禁止报告写入、禁止估值计算分别检查；工具入口重新读取当前会话中的最后一条用户消息。模型工具参数和旧 run.question 均不能覆盖限制。

报告写入限制也拦截 start_research，避免绕路生成新底稿。联网限制涵盖公司目录查询、财务研究、年报获取、搜索、网页/PDF下载与深度生成。已经授权离线修订且存在可用来源时，可选 refine；普通生成保存、场景采用、材料读取保持原有能力。报告工具实际 question 使用最新用户消息。显式搜索组数在搜索分派处检查。

Agent context 接入价值组 report_valuation_status，只提示新情景与旧报告的关系，不自动触发写报告。

### 2. 由实际阅读结果形成可保存覆盖与来源状态

明确要求正文时，模型过早结束且只有摘要，程序在剩余决策预算内最多补读两个未尝试链接。禁止联网时不补外部请求；没有链接、预算不足、读取失败、空正文、仅 PDF 链接时保留缺口，回复增加正文查证未完成说明。

结构化 turn_coverage 写入本轮会话与助手消息，含搜索次数/结果数、新增网络正文数、本地实际读页数、引用已有正文数、失败/未读来源与 partial/observed 状态。搜索摘要永不计正文；已有资料必须实际有正文并被最终回答链接引用，才计为复用。observed 只表示观察到的覆盖，不等于事实已核验、结论已证实或任务全部完成。

嵌套 build 只提取单次调用前后实际变化的来源记录与该次返回的 searches 日志；不使用累计 web_bodies 作为本轮正文数。旧嵌套记录缺少逐轮证据时 UI 显示未知，不回填累计数字。失败的嵌套调用可能保留了部分来源，但没有可靠返回日志时本轮覆盖不声称已计入。

网络来源按规范 URL（HTTP/HTTPS、fragment、utm）去重，正文状态不会被随后摘要覆盖；已读/被引用来源优先。侧栏显示总数、默认 8 条、可展开全部。旧成长记录仅用其已有 steps 只读回放，显示 1 / 18 / 0 与正文未完成，不修改历史记录。网页读过不等于已核实；正文选摘也不声称读完整份 PDF。
